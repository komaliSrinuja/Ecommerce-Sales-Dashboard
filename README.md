# E-Commerce Sales Dashboard

## Project Overview
An interactive Power BI dashboard for analyzing e-commerce sales performance using the Olist dataset.

## Tools Used
- Power BI
- DAX
- MySQL
- Data Visualization

## Key Features
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Monthly Sales Trend
- Sales by Product Category
- Payment Methods Analysis
- Sales by State
